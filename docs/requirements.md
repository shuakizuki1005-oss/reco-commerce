# RecoCommerce 要件定義書

## 1. プロジェクト概要

### 1.1 プロジェクト名
RecoCommerce

### 1.2 目的
Python、TypeScript、機械学習を活用した
レコメンド機能付きECプラットフォームの開発

### 1.3 開発目標
- フルスタックwebアプリ開発
- PythonとTypeScriptの取得
- 機械学習モデルの設計・学習・評価
- API設計とデータベース設計
- テスト自動化とCI/CDの導入
- GitHubを利用した実務的な開発

## 2. 対象ユーザー

- 商品を購入する一般ユーザー
- 商品を管理するECサイト運営者

## 3. 機能要件

### 3. 1 一般ユーザー登録
- ユーザ登録・ログイン
- 商品一覧表示
- 商品検索・絞り込み
- 商品詳細表示
- カート管理
- お気に入りに登録
- 模擬注文
- 注文履歴確認

### 3.2 管理者機能
- 商品登録・編集・削除
- 商品カテゴリ管理
- 在庫管理
- 注文管理
- 売り上げ分析ダッシュボード

### 3.3 機械学習機能
- 類似商品の推薦
- 閲覧履歴に基づく推薦
- 購入履歴に基づく推薦
- 推薦モデルの学習と評価
- 推薦結果の可視化

## 4. 非機能要件

- ローカル環境で無料開発
- PC・スマートフォンで利用できること
- ユーザーごとのアクセス権限を管理すること
- 入力値のエラー処理を行うこと
- 自動テストを導入すること
- API仕様書を整備すること

## 5. 技術スタック

### Frontend
- TypeScript
- Next.js
- React

### Backend
- Python
- FastAPI

### Machine Learning
- scikit-learn
- pandas
- NumPy

### Database
- SQLite

### Testing
- pytest
- Playwright

### Version Control
- Git
- GitHub

### 6. MVP

最初に実装する機能：
- 商品一覧
- 商品詳細
- 商品検索
- カート
- 商品取得API
- SQLiteでの商品管理
- ルールベースの類似商品推薦

本格的な機械学習、認証、注文・管理者機能は
MVP完成後に段階的に追加する。

## 7. 開発方針

- Issue単位で開発する
- Issueごとにブランチを作成する
- Pull Requestを経由してmainに統合する
- PythonとTypeScriptの文法学習を並行する
- 機械学習を基礎から段階的に導入する
